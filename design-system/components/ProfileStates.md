# ProfileStates (draft)

The profile's other tab and states:

1. **Account**: display name, email, password and Sign out, as label/value rows on hairlines.
2. **Student · nothing yet**: the Student tab before any request or interest, with the way to the seminars.
3. **Signed out**: one line and Sign in, which brings you back here.

The Teacher tab has its own card (ProfileTeacher).
