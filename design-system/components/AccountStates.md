# AccountStates (draft)

The account page's other states, side by side, each as it would replace the forms in AccountPage's working column:

1. **Create an account**: Continue with Google, or email and a password (shown on demand) twice. Creating signs you in at once.
2. **Set or reset a password**: one email field; the confirmation shows under it once the link is sent.
3. **From the email link**: choose the new password.
4. **Password saved**: back to sign in.
5. **Signed in · request enrollment**: when the page was opened for a seminar, the request (name, X handle, why) follows sign-in on the same page, with the seminar named in the pink-ruled line.
6. **Awaiting confirmation**: the one action that matters now (send the DM from the registered handle), marked with the pink Action required badge, then the way on to the profile.
7. **set-password.html**: the same form for someone already signed in.
8. **auth-action.html**: the interstitial while an email link is opened.

The wording follows the site's own. One primary button per state.
