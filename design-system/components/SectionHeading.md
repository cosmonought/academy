# SectionHeading

A small bold heading in Barlow caps (`text-heading`) that names a group of panels: "Seminar access", "The journal".

## Use
- Above a row of panels, left-aligned with the first panel's text, `space-5` above the first IndexRule.
- Write it in sentence case; CSS sets the caps.
- Page titles are NDA Display (`display-headline`), not this.

## Markup
```html
<h2 class="nda-section-heading">Seminar access</h2>
```
